## Install

Download **`PasswordManager-win-Setup.exe`** below and run it. No admin rights are needed. Already installed? The app updates itself.

The browser extension is attached below as `password-manager-extension-chromium-….zip` (Chrome, Edge, Brave, Opera, Opera GX) and `…-firefox-….zip`. See the [User Guide](https://github.com/gaaloulv36/password-manager/blob/main/docs/USER-GUIDE.md#8-the-browser-extension) for how to install it.
