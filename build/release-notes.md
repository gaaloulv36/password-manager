## Install

Download **`VaultForge-vaultforge-Setup.exe`** below and run it. No admin rights are needed. Already installed? The app updates itself.

Coming from the earlier **Password Manager** (1.0.x)? It doesn't update to VaultForge by itself. Exit it, install VaultForge once, check your vault opens, then uninstall Password Manager from Windows Settings → Apps. Your settings, backups, Windows Hello and connected browsers come along. Reload the browser extension from the new zip.

The browser extension is attached below as `vaultforge-extension-chromium-….zip` (Chrome, Edge, Brave, Opera, Opera GX) and `…-firefox-….zip`. See the [User Guide](https://github.com/gaaloulv36/vaultforge/blob/main/docs/USER-GUIDE.md#8-the-browser-extension) for how to install it.
